# feedback-repo-copy

Copy of the Saga senior-to-junior feedback UI prototype for editing and iteration.

The repo holds a self-contained HTML concept draft. Open it in a browser to review the layout and keep changing it with help.

## View the prototype

- **On GitHub Pages (after merge to `main`):** [https://celinemarielund.github.io/feedback-repo-copy/](https://celinemarielund.github.io/feedback-repo-copy/)
- **Locally:** open `index.html` in your browser, or serve the repo root with any static file server.
